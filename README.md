# Mod Menu Lite (Fabric 1.21.11)

Press Right Shift (changeable in Controls) to open the menu: Chest ESP, Freecam, DonutSMP auction prices.

## Build without installing anything
1. Create a free GitHub account and a new repository.
2. Upload ALL files of this folder (drag & drop works, include the hidden .github folder).
3. Open the "Actions" tab, wait until "Build mod" is green, open it and download "modmenu-lite-jar".
4. Unzip it and put the .jar into your mods folder (together with Fabric API).
